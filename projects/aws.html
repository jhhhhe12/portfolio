• 프로젝트 개요

AWS 클라우드 서비스를 활용하여 고가용성, 확장 가능한 인프라를 설계하고 구현한 프로젝트입니다.
Infrastructure as Code(IaC) 접근 방식을 통해 자동화된 배포 파이프라인을 구축하고, Multi-AZ 구성과 Auto Scaling을 통해 안정적이고 탄력적인 서비스 운영 환경을 제공합니다.

• AWS 인프라 아키텍처

📊

AWS 아키텍처 다이어그램

Internet Gateway → ALB (Application Load Balancer)
→ Multi-AZ EC2 Auto Scaling Group
→ RDS Multi-AZ (Primary + Standby)
→ S3 (Static Assets) + CloudFront CDN

VPC 내부에 Public/Private Subnet을 분리하여 보안성을 높이고, NAT Gateway를 통해 Private Subnet의 외부 통신을 안전하게 처리합니다.

• 기술적 도전

💰 비용 최적화

초기 클라우드 비용이 예상보다 높게 발생하는 문제를 Reserved Instance와 Spot Instance를 전략적으로 활용하여 월 운영 비용을 40% 절감했습니다.

🔄 무중단 배포 구현

업데이트 시 서비스 중단이 발생하는 문제를 Blue-Green Deployment 전략과 ALB 타겟 그룹 전환으로 무중단 배포를 구현했습니다.

🔒 보안 강화

VPC, Security Group, NACL을 활용한 다층 보안 구조를 설계하고 IAM 역할 기반 접근 제어로 최소 권한 원칙을 적용했습니다.
