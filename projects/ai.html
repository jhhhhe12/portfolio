• 프로젝트 개요

주차장의 주차 공간 이용 현황을 한눈에 파악할 수 있도록, AI가 차량을 자동으로 인식하고 슬롯별 점유 상태를 계산합니다. 그 결과를 전체 주차장 현황과 함께 색상 박스로 직관적으로 표시하여 실시간 모니터링이 가능하도록 구현했습니다.

• 기술적 도전

⚡ 실시간 처리 성능 최적화

고해상도 영상 처리 시 프레임 드롭 문제를 TensorRT 모델 최적화로 해결하여 추론 속도를 3배 향상시켰습니다.

🎯 다양한 환경에서의 정확도 개선

조명, 각도, 배경 변화에 따른 감지 정확도 편차를 Data Augmentation과 Transfer Learning 기법으로 mAP 88%까지 향상시켰습니다.

🦴 골격 추출 안정화

MediaPipe를 활용한 33개 신체 랜드마크 추출 시 흔들림과 노이즈를 칼만 필터로 안정화하여 분석 정확도를 높였습니다.
