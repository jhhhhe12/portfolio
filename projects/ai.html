• 프로젝트 개요

딥러닝 기반 보행 패턴 분석 시스템으로, 영상 데이터에서 사람의 보행 자세를 실시간으로 분석하고 이상 패턴을 자동으로 감지하는 AI 모델을 개발했습니다.
의료 및 재활 분야에서 환자의 보행 상태를 모니터링하는 데 활용될 수 있으며, YOLOv8과 MediaPipe를 활용한 정확한 자세 추정과 실시간 분석이 가능합니다.

• 시스템 아키텍처

📊

AI 파이프라인 다이어그램

Video Input → Object Detection (YOLOv8) → Pose Estimation (MediaPipe) → Pattern Analysis → Result Output

• 기술적 도전

⚡ 실시간 처리 성능 최적화

고해상도 영상 처리 시 프레임 드롭 문제를 TensorRT 모델 최적화로 해결하여 추론 속도를 3배 향상시켰습니다.

🎯 다양한 환경에서의 정확도 개선

조명, 각도, 배경 변화에 따른 감지 정확도 편차를 Data Augmentation과 Transfer Learning 기법으로 mAP 88%까지 향상시켰습니다.

🦴 골격 추출 안정화

MediaPipe를 활용한 33개 신체 랜드마크 추출 시 흔들림과 노이즈를 칼만 필터로 안정화하여 분석 정확도를 높였습니다.
